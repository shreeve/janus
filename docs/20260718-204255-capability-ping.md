# Capability: ping

Cold Caddyfile capability. When enabled for a site, `GET /ping` returns `pong`.

| | |
| --- | --- |
| **Order** | **1 — primordial** (needs nothing else) |
| **Surface** | Cold config (Caddyfile) |
| **Cascades** | Yes — global default → site override |
| **Built-in default** | off (when unset at every level) |
| **Module** | Site handler reads global `janus` app + site override |
| **Status** | Implemented |

## Why it exists

The first Janus capability on purpose: prove the module loads, TLS works, sites admit into Janus, and cascade rules hold — with **no** control plane and **no** `/1.0`.

Also a tiny data-plane liveness check for smoke tests and demos. Distinct from control-plane `GET /1.0/health` (capability **control**, order 2).

Default **off** so public hosts do not advertise `/ping` unless you opt in (globally or per site).

## Cascade

Site-scoped capabilities inherit from the global `janus` block unless the site sets them.

| Global | Site | Effective |
| --- | --- | --- |
| (unset) | (unset) | **off** |
| `ping` / `ping on` | (unset) | **on** |
| `ping` | `ping off` | **off** |
| `ping off` | `ping` / `ping on` | **on** |

Process-wide capabilities (**control**) do **not** cascade and must not appear in site blocks.

## Syntax

The working tree uses `*.janus.localhost` names (always → the loopback, no DNS) with certificates from Caddy's internal CA — see the root `Caddyfile`.

```caddyfile
{
	janus {
		control local
		ping                 # global default on
	}
}

*.janus.localhost {                # catchall: inherit on
	janus
}

on.janus.localhost {
	janus {
		ping on              # explicit on
	}
}

off.janus.localhost {
	janus {
		ping off             # explicit off
	}
}
```

### Legal lines

```text
ping
ping on
ping off
```

## Verify

High-level acceptance (preferred):

```bash
./test.sh
# == ping ==
#   ✓ catchall foo.janus.localhost → pong
#   ✓ on.janus.localhost explicit on → pong
#   ✓ off.janus.localhost explicit off → 404
#   …
```

Manual:

```bash
./bin/janus run
curl -s https://foo.janus.localhost/ping          # catchall inherit → pong
curl -s https://on.janus.localhost/ping           # explicit on → pong
curl -s -o /dev/null -w '%{http_code}\n' https://off.janus.localhost/ping
# → 404
```

No `-k` needed — the wildcard is publicly trusted. Developer unit tests remain `go test ./...`.

## Non-goals

- Replacing `/1.0/health`
- Auth, metrics, or elaborate health payloads
- Enabling ping on the control listeners (data plane only)

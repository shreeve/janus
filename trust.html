One-time setup for this device

Names served here use a private certificate authority that lives only on this edge. Teach this device to trust it once, and every local site gets a real lock — no warnings, in any browser.

iPhone / iPad

One Safari step. iOS lets only Safari hand a trust profile to Settings; every other browser can only save it as a dead file. The button below jumps you there.

  1. 1
    Download trust profile
    Safari asks to allow a configuration profile — tap Allow.
    Open in Safari & download
    Tap Open when your browser asks. Safari will warn “This Connection Is Not Private” — expected; the trust you are installing is what fixes it. Tap Show Details → visit this website, then Allow the download.
    Nothing happen? Open Safari yourself and go to — this page appears there with a direct button.
  2. 2
    Open the Settings app and tap the downloaded profile — under Profile Downloaded near the top, or in General → VPN & Device Management — then Install.
  3. 3
    Still in Settings: General → About, scroll to Certificate Trust Settings, and switch on the certificate named Caddy Local Authority. (This is the step everyone misses — HTTPS does not work without it.)
  4. ✓
    Open any browser you like — this page notices automatically and takes you in.

Android

  1. 1
    Download CA certificate
  2. 2
    Open Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate, then pick the downloaded file. (Menu names vary by phone.)
  3. ✓
    Come back here — this page notices automatically and takes you in.

Mac

  1. 1
    On the machine running this edge: janus trust
  2. 2
    On any other Mac: download the CA certificate, double-click it into Keychain Access, then set it to Always Trust.

Other devices

Download the CA certificate and import it as a trusted root certificate in your system or browser settings.

Not this device? watching for trust
The certificate authority's private key never leaves the machine running this edge. Trust is per device and can be removed at any time in the device's settings.
